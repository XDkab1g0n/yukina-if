# 偶像雪奈 IF

**狀態：構想中。** 記錄 2026-11-22 的討論，供日後接續。

## 分歧點

朔夜兄妹當年沒有被佐藤發掘。兩人靠彼此在新東京生活，雪奈被星探看中後，踏上偶像路線。這條線關心的是兄妹能否在城市裡慢慢過上安穩日子，以及雪奈有了舞台之後，怎麼為自己的生活做選擇。

## 目前的發展方向

- **雪人與兄妹生活。** 討論中的版本是雪人先靠技術工作維生，負擔住處、食物與雪奈的教育。等兩人生活穩定後，他有機會重拾醫學。兄妹可以繼續一起住，有自己的家和各自想做的事。
- **雪奈的演藝路。** 暫採她沒有走過巖本的地獄鍛鍊。保有先天的動作天分，發展到舞蹈、表演與舞台，實際體能依本線的成長經歷設定。童星、廣告、舞蹈、演員兼偶像都曾討論，出道年齡及先後次序待定。十八歲是目前討論偶像雪奈時採用的時間點。
- **雪奈逆指名奏。** 雪奈主動要求奏跟自己的工作。奏保有「黑貓」的身手。曾討論的配置是十五歲的奏擔任專屬經紀助理／行程統籌，實際跟場、照看安全，正式合約由成年經紀人處理。職稱、年齡和職責細節是暫案。
- **雪奈與奏。** 她們可以發展成戀人。逆指名可以是感情與工作開始交疊的契機。相遇經過、誰先意識到自己的心意、兩人何時交往，留給後續故事決定。
