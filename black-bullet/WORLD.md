## 1. 大戰與戰後政體

- **2021 年 Gastrea 大戰。** 人類戰敗，失去大部分領土，倖存者集中在以巨石碑防守的居住區。2031 年是動畫的開篇年份，大戰記憶仍是居民的切身經歷。［S1、S2］
- **日本五個 Area。** 東京、北海道、仙台、大阪、博多。它們是戰後防衛與治理形成的居住區，現代都道府縣、消防或警政轄界需要另有故事依據才可沿用。官方出版資訊也確認日本五區分治，東京由聖天子領導，大阪的代表為斉武宗玄。［S1、S4、S5］
- **東京有區內權力，也有區際政治。** 聖天子是統治者，天童菊之丞任補佐官。護衛、民警公務委託和區際會談可以同時存在，彼此有各自的承辦與資訊範圍。［S4］

## 2. 東京 Area 與巨石碑

- **城內有一條由中心到邊緣的落差。** 官方動畫用語集載東京有 43 區。第一區周邊較繁榮，靠近防線的外周區多是廢墟，也有人居住於地下與下水道。第四十區有第二次關東會戰紀念碑「回歸之炎」。外周區、巨石碑周邊與邊界之外宜按實際場景定位。［S1］
- **巨石碑（Monolith）是外圍防線。** 多面巨型錵板間隔排列，錵產生的特殊磁場使一般 Gastrea 迴避。動畫用語集列東京碑高約 1.618 公里、寬約 1 公里，約每 10 公里一座；這些是該資料的東京數值。Stage V 可無視磁場，少數其他階段的個體也可能以特性破壞碑的作用。［S1、S6］
- **錵（Varanium）同時是戰略資源。** 這種黑色架空金屬會抑制 Gastrea 的再生，也用於巨石碑與對 Gastrea 裝備。原作者在動畫用語集中提及日本是重要產區。磁場阻隔、材料抑制再生與個體被擊倒是三件不同的事，場面依個體和事件分開判斷。［S1］
- **場景取用。** 寫通勤、撤離、工程或救援時，可從生活圈、服務是否仍在運轉、外周區居民能否取得支援等條件發展。精確街廓、供水路線與住民分布按本線已寫地點或單篇新創，避免把一個外周區的處境泛用到全東京。

## 3. Gastrea 與階段

| 項目 | 已知規則 | 用在故事時 |
|---|---|---|
| Gastrea／原腸動物 | 大戰的異形生物，有極強的再生能力。外形及能力和動物因子相關 | 交代目擊到的特徵、判定根據與當下威脅。一般火力的效果要呈現再生帶來的後果 |
| Stage I–IV | 原作者以感染後的成長程度解釋通常分類，較高階可呈現複合因子 | 階段提供基本尺度；能力、體量、特殊性及環境仍決定單次交鋒 |
| Stage V／Zodiac | 超出普通四階的特異級個體，能越過一般錵磁場的防線；原作開場基準為已知十一體，其中兩體已遭擊破 | 數量要跟著故事時間更新，官署、民警與居民的消息也可有落差 |
| 侵蝕率 | 動畫用語集描述感染者超過 50% 會發生形象崩解並 Gastrea 化 | 澪的追蹤與停止條件讀其角色卡 §17–18。線上資料未確定她各動作的精確代價 |

來源［S1］。本線的雪奈與澪在這個世界的實際戰力及限制，另查雪奈主設定 §8–§10、§12.7、§14 和澪卡 §5、§10、§17–§18。

## 4. 受詛之子、生活與法律

**受詛之子**是在母體內感染、出生時便帶有 Gastrea 病毒與抑制因子的孩子；動畫開篇時記載僅確認到女孩。動物因子使她們有不同的能力與體徵，常見超常運動能力和再生，發動能力可見紅眼，部分孩子具有動物外觀。使用能力會推高侵蝕率，日常有抑制劑。**Initiator** 特指當中參與民警工作、與 Promoter 搭檔的人，孩子在制度之外仍有生活、關係與選擇。［S1］

- **被奪走的世代／無垢的世代。** 前者指遭逢大戰的人，戰爭造成的喪失與恐懼是偏見的重要背景。後者指戰後出生的人，其中包含受詛之子。遭排擠的部分孩子在外周區下水道生活，動畫也有外周區孩子參加露天教室的場景。［S1、S6］
- **Gastrea 新法。** 聖天子提出保障受詛之子基本人權的法案，面臨強烈反對。開篇採提案受阻的狀態。後續若要寫適用法條、執行機關或生效日，先釘住篇章時間與來源。［S1］
- **日常可以有溫度。** 官方設定中的《天誅少女》（天誅ガールズ）是延珠喜歡的魔法少女動畫，幻庵祭則是戰後慰靈活動。城市同時有紀念、娛樂與學校生活。［S1、S2］

## 5. 民警、IISO、IP 序列

| 名稱 | 職能與適用範圍 |
|---|---|
| 民警 | 原作的民間警備公司，通常以兩人搭檔處理 Gastrea 相關任務；公司也可接正式護衛。 |
| Promoter | 民警搭檔的一方，通常負責協調與指揮，也可能是孩子的重要支持。具體分工依當事人和委託而異。 |
| Initiator | 民警搭檔的另一方，使用動物因子相關的能力；能力、侵蝕及照護需按角色與時期處理。 |
| IISO | 國際 Initiator 監督機構（International Initiator Supervising Organization）。負責監督、配對及序列，動畫用語集記載當期全球登錄逾二十萬組。 |
| IP 序列 | 按搭檔整體能力與實績排出，各級可有不同機密資訊權限及有事時的準階級。公開資料沒有給出完整計算公式或各名次權限表。 |
| Adjuvant | 動畫危機章的民警聯合編組，臨時納入自衛隊體系，由多組搭檔形成小隊，依當次指揮架構運作。 |

來源［S1、S4］。碰到關卡放行、調閱機密、醫療同意或指揮他人時，要確認哪個單位授權、授權範圍與事件時點。序列描述登錄搭檔的制度位置，人物單打尺度按人物檔。

## 7. 雪奈線採用的時間與制度

| 時點／項目 | 本線設定與回查 |
|---|---|
| 2021 年 | 雪奈約七至八歲，父母死於大戰或其直接後果。戰後和雪人相依，再被佐藤發掘。主設定 §15.1。 |
| 《相遇之前》 | 第一章是零夜參與供水工程，雪奈當時正在考慮補辦 Promoter 資格。其後才依章稿發展她與澪的初見和合作。主設定 §15.3、澪卡 §12–14、[章稿順序](README.md#相遇之前)。 |
| 2031 年本篇開場 | 雪奈是勾田高校三年級，已和澪登錄搭檔約六週，組合 IP 約 700–900。開場尚未認識蓮太郎、延珠或木更，與蓮太郎同校不同年級。主設定 §5.1、§7.7、§16。 |
| 朔夜家的日常與公司 | 雪人與雪奈同住，住家與公司分址；雪人營運，雪奈和澪成組，奏另有一組。澪初期有自己的住處。主設定 §16、澪卡 §15–16。 |
| 三層身分 | 通常能查的是登錄 Promoter。公務接觸者可能知道零夜呼號；IISO 有權限的審查層知道其正式履歷。含聖天子在內的少數高權限者才掌握三層對照；澪的知情狀態跟著當期正文。主設定 §7.8。 |
| 朔夜民警、零夜、銀色幽靈 | 可合法承接公開案件的公司、各自授權的公共工作與地下委託都在同一座城活動。銜尾蛇是本線的跨 Area 地下網路；它的資源或委託不能自行移轉成朔夜民警的公權限。主設定 §6–7、§15–16、澪卡 §15。 |
| 澪的自主與照護 | 兩人各自選擇是否出勤；符合當事人事前議定條件時有緊急中止權。雪人管理澪的長期身體狀態。主設定 §7.7、澪卡 §17–18。 |

**尚未確定。** 原作大事件與《相遇之前》及本篇開場的精確相對時序、住家及辦公室所在區與地址、奏的 Initiator、未來 IP 精確名次、朔夜組和原作人物的交會結果。凡場景依賴這些事，依[資料導覽](source_guide.md)找到主管檔，並把新增前提留在該篇。
