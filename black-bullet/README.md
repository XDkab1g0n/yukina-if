# 《黑色子彈》世界線

《雪奈／ZERO NIGHT》與《黑色子彈》的同人跨作品世界線。此線以 2031 年東京 Area 為背景，雪奈就讀勾田高校，與雪人共同生活，並在自己的民警工作中與風見澪搭檔。

## 設定入口

- [風見澪正式角色卡 v1.1](canon/風見澪_Model_Peregrine_Falcon_Initiator_v1.1.md)裁決澪自身的外觀、能力、裝備與成長經歷。
