# 《黑色子彈》世界線

《雪奈／ZERO NIGHT》與《黑色子彈》的同人跨作品世界線。此線以 2031 年東京 Area 為背景，雪奈就讀勾田高校，與雪人共同生活，並在自己的民警工作中與風見澪搭檔。

## 依任務讀什麼

| 任務 | 讀取入口 |
|---|---|
| 東京、巨石碑、錵、Gastrea、受詛之子、IISO、IP 序列與原作人物 | [世界觀基準](WORLD.md) |
| 雪奈、澪、身分、能力、裝備或許可 | [資料導覽](source_guide.md)及下面的人物主管檔 |
| 寫新篇或審稿 | [寫作指南](WRITING_GUIDE.md)及[寫作流程 v4](method/LOOP.md) |
| 接著寫《相遇之前》 | [章稿順序](#相遇之前)與當期設定；已有工作對帳時一併讀取 |

同一項工作鎖定同一個 commit，再依任務取用資料。原世界線引入的是創作方法；這裡的世界與人物以黑彈線資料為準。正文用繁體中文及台灣用語。定稿放在 `black-bullet/stories/`，工作檔放在 `black-bullet/workshop/`；工作筆記保持在正文之外。

## 設定入口

- [朔夜雪奈獨立主設定 v1.3](canon/朔夜雪奈_黑色子彈世界線_獨立主設定_v1.3.md)是本線現行設定，裁決雪奈的能力、成長史、身分與關係。v1.2 為歷史稿。
- [風見澪正式角色卡 v1.1](canon/風見澪_Model_Peregrine_Falcon_Initiator_v1.1.md)裁決澪自身的外觀、能力、裝備與成長經歷。

一般世界規則以世界觀基準及所列來源為依據；本線的能力、私史、關係及具體權限由人物主管檔裁決。故事當時發生過的事、目前的傷勢、裝備與所知查當期正文。場景、委託或配角可按該篇需要新創，核心設定或長期關係要升格才由 Charles 決定。
